# qa-course-bt

Description:

This program generates a Fibonacci sequence and tests it based on the number entered by the user. The program asks the user to enter how many Fibonacci numbers should be generated.

Example:

Input: 5
Output: 0 1 1 2 3
The program has validation:

If the input is not a number(int), it prints: "Entered data is not valid!"
If the number is 0 or less, it prints: "The number must be higher than zero!"
Approaches:

Java;
Scanner;
if / else statements;
Nested if statements;
for loop.
